### 问题

- default/failure场景

目的：模拟agent在使用search工具时，网络请求失败的场景
效果：返回403，404等状态码

考虑实际的场景，我现在只有一个search工具，是不是不应该设置成apply_always（就是每一次调工具都返回网络错误），要不然模型反复请求，一直都是失败，一直达到max_turns，那感觉所有的task都会失败，agent表现直接变成0了。

师兄现在的逻辑好像是：只要agent调用工具，就随机返回403，404等一种状态码。

感觉可以设置成：
模拟现实中网络不佳的情况，比如每一次请求有70%的概率成功，30%的概率失败（返回403，404等状态码）。这样模型有可能多次尝试调用工具，最终成功完成任务。
即
apply_always: false
